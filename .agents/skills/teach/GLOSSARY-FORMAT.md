# `GLOSSARY.md` format

`GLOSSARY.md` is the ordered course plan and the canonical language for the workspace. Create it before the first lesson.

## Template

```md
# {Topic} glossary

{One or two sentences that define the scope of the course.}

## Terms

### 1. {First term}

{A definition of one or two short sentences.}

Avoid: {aliases that the course will not use}

### 2. {Second term}

{A definition of one or two short sentences.}

Avoid: {aliases that the course will not use}
```

## Rules

- Put prerequisites before concepts that depend on them.
- Give each term one stable position and number.
- Create one lesson for each term, in this exact order.
- Use the term number as the lesson number.
- Use one canonical term for each concept. List ambiguous aliases after `Avoid:`.
- Keep each definition to one or two sentences.
- Use established glossary terms inside later definitions.
- Include only terms that support the mission.
- Revise definitions when the learner gains deeper knowledge.

If the order changes after lessons exist, rename the affected lessons and repair every lesson navigation link.
